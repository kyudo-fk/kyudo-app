# 弓道フォームAI

端末から弓道動画を選択すると、ブラウザ上でMoveNetを使って姿勢を解析する練習用Webアプリです。


## 使い方

1. 「端末から動画を選択」を押す
2. 動画を選ぶ
3. 自動で解析開始
4. 総合スコア、良かった点、改善ポイント、離れ候補、八節の参考評価を確認

## 注意

- カメラ撮影機能はありません。
- 動画は端末から選択し、ブラウザ上で解析します。
- MP4（H.264）を推奨します。
- 評価は練習用の参考指標であり、弓道の技術を確定判定するものではありません。
- TensorFlow.js / MoveNetをCDNから読み込みます。
